# Unducked

Unducked is not a search engine. It is a search engine redirector: add it to your browser as a custom search engine, and
each query you type is forwarded to the provider.

## How it works

1. Your browser sends a query to Unducked, e.g. `http://localhost:3000/search?q=rust+lifetimes`.
2. Unducked answers with an HTTP `301 Moved Permanently` whose `Location` header points at the real search engine.
3. Your browser follows the redirect and shows the results.

Unducked never sees or stores results. It only decides where to send the query.

### Routing rules

| Query                 | Redirects to                                                                                   |
| --------------------- | ---------------------------------------------------------------------------------------------- |
| `rust lifetimes`      | `https://www.google.com/search?q=...`                                                          |
| `!ddg rust lifetimes` | `https://duckduckgo.com/?q=rust lifetimes` (the `!ddg` is stripped)                            |
| `!w rust lifetimes`   | `https://duckduckgo.com/?q=!w rust lifetimes` (any other bang is passed through to DuckDuckGo) |

The default engine is Google (`SearchEngineProvidier::GOOGLE` in `src/service/search_engine_provider_service.rs`). DuckDuckGo is available as a provider variant but is not the default.

## Endpoints

| Method | Path              | Description                                                                |
| ------ | ----------------- | -------------------------------------------------------------------------- |
| GET    | `/`               | Landing page with setup instructions (`static/index.html`).                |
| GET    | `/search?q=...`   | Redirects the query to the configured search engine (301 + `Location`).    |
| GET    | `/opensearch.xml` | OpenSearch description so browsers can offer "Add Unducked" automatically. |
| GET    | `/docs`           | Swagger UI for the OpenAPI spec generated by `poem-openapi`.               |

## Adding Unducked to your browser

**Automatic:** open the landing page, right-click the address bar, and choose **Add Unducked** (browsers that support OpenSearch will offer this).

**Manual:** in your browser's search engine settings, add a new engine with:

- Name: `Unducked`
- Keyword: `unducked`
- URL: `http://localhost:3000/search?q=%s` (replace with your own host when deployed)

## Running locally

Requirements: Rust (edition 2024 toolchain).

```sh
cargo run
```

The server binds to `0.0.0.0:3000`, so open <http://localhost:3000> in your browser.

Logging uses `tracing` and defaults to `RUST_LOG=debug` if `RUST_LOG` is not set.

### Auto-reload during development

`tasks.py` defines an [invoke](https://www.pyinvoke.org/) task that restarts `cargo run` when `.rs` or `.sql` files change, using [watchdog](https://github.com/gorakhargosh/watchdog)'s `watchmedo`.

```sh
pip install invoke watchdog   # or install via uv tool
invoke dev
```

## Docker

`dockerfile` is a multi-stage cargo-chef build (Rust builder, distroless `cc-debian12` runtime):

```sh
docker build -f dockerfile -t unducked .
docker run --rm -p 3000:3000 unducked
```

## Project layout

```
src/
├── main.rs                              # Server setup, route table, logging init
├── constants/values.rs                  # Bang regex
├── controller/
│   ├── search.rs                        # GET /search redirect handler
│   ├── opensearch_metadata.rs           # GET /opensearch.xml
│   └── static_files.rs                  # Serves static/ at /
├── service/search_engine_provider_service.rs  # Builds the target search URL
├── dto/, types/, error/                 # Response types and error plumbing
static/
└── index.html                           # Landing page
```

## Stack

- [Poem](https://github.com/poem-web/poem) and [poem-openapi](https://github.com/poem-web/poem-openapi) for HTTP, OpenAPI, and Swagger UI
- [Tokio](https://tokio.rs/) async runtime
- [color-eyre](https://github.com/eyre-rs/color-eyre) and [thiserror](https://github.com/dtolnay/thiserror) for errors
- [tracing](https://github.com/tokio-rs/tracing) for logs
- Landing page styled with Tailwind CSS 4 and daisyUI 5 (loaded from CDN)
